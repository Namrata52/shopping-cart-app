# 🛒 Shopping Cart App

A modern React application built to practice **Redux Toolkit** and efficient **state management**. The project demonstrates how to fetch products from an API, manage global state with Redux, and provide a seamless shopping cart experience with real-time updates.

## 🚀 Features

* 📦 Fetches products dynamically from an API
* ➕ Add products to the shopping cart
* ➖ Remove products from the cart
* 🔄 Real-time state updates using Redux Toolkit
* 🧮 Automatic cart total calculations
* 🛍️ Dynamic cart item count and pricing
* 📭 Gracefully handles empty cart scenarios
* 📱 Responsive and user-friendly interface

## 🛠️ Tech Stack

* **React**
* **Redux Toolkit**
* **React Redux**
* **JavaScript (ES6+)**
* **CSS**

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Namrata52/shopping-cart-app.git
```

Navigate to the project folder:

```bash
cd shopping-cart-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```
